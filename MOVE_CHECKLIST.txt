 ⭐ MÁY WINDOWS SẠCH 100% — RUNTIME HỆ THỐNG (cài TRƯỚC khi chạy MSI)
==========================================================================
 App là .exe đóng gói PyInstaller → Python của app đã nhúng sẵn,
 KHÔNG cần cài Python cho phần lõi. Nhưng vẫn cần runtime sau:

 [ ] (BẮT BUỘC) Microsoft Visual C++ Redistributable 2015-2022 (x64)
         → file: vc_redist.x64.exe  (tải từ Microsoft)
         → cung cấp vcruntime140.dll cho Python/torch/numpy
         → ⚠ ĐÂY LÀ THỨ HAY THIẾU NHẤT trên Win mới. Không có →
           app báo thiếu DLL / không mở được.

 [ ] (NẾU CÓ CARD NVIDIA) NVIDIA GPU Driver (Game Ready / Studio mới)
         → bật h264_nvenc cho video + cuda:0 cho RVC/VoxCPM/Whisper
         → KHÔNG cần cài CUDA Toolkit riêng (torch đã gói CUDA cu126)
         → Không có GPU → app tự fallback libx264 + cpu (chậm hơn,
           vẫn chạy)

 [ ] .NET Framework 4.8 (Win10/11 thường CÓ SẴN)
         → chỉ cần cho Subtitle Edit. App lõi không cần.

 [ ] Kết nối Internet
         → Edge TTS + tất cả provider TTS gọi API online
         → lần đầu tự tải model Whisper / Silero VAD / Demucs

 THỨ TỰ CÀI TRÊN MÁY SẠCH:
   1. Windows update cơ bản (đảm bảo .NET 4.8)
   2. vc_redist.x64.exe          ← QUAN TRỌNG, hay quên
   3. (nếu có NVIDIA) driver GPU
   4. SRT_TTS_Studio_Setup.msi
   5. Mở app, test Edge TTS  → xong phần lõi
   6. (nâng cao) copy voxcpm_env + VoxCPM model + VideOCR
   7. ⚙ Cài đặt → trỏ 4 đường dẫn → lưu
   8. Cài Subtitle Edit nếu cần
